Open this page on your phone

Three steps

  1. Download and open the file. Tap the APK in your Downloads or Files app.
  2. Allow installs from that app. Android asks once; then tap Install.
  3. Allow Notification Access. The first screen explains why. It reads only M-Pesa confirmations.

If it will not install

Samsung: Auto Blocker

One UI 6.1 and newer block sideloaded apps by default. Settings → Security and privacy → Auto Blocker → off, install, then turn it back on.

Google Play Protect

If the warning only offers "OK", open Play Store → profile → Play Protect → gear → Scan apps with Play Protect → off, install, then turn it back on. On some builds "More details → Install anyway" is enough.

Chrome refuses the download

Choose Download anyway, or open this page in Samsung Internet, or download on a computer and copy the file over.

Updates

Pocket Ledger has no network permission, so it cannot check for updates itself. Either come back to this page, or let Obtainium watch this repository's releases and install each new version over the old one.
